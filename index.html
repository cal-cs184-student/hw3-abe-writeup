Part 4: Global Illumination

The indirect lighting function is basically checking the light at one point and then recursively checking the light at a random angle from that point and then checking what the light there is. And then using that to add it to the light at the original point so that you can get the light that's being reflected. The recursively added light is multiplied by a factor of f times cosine theta divided by the PDF. F being the reflectance constant.

The unaccumulated bounces show the light from the bouncing. And this means it's getting the light from the bounces when it gets accumulated up, which doesn't happen for rasterization because it only takes into account the light and not the bouncing. The third bounce shows marginally more brightness at the corners and the edges.

As the M goes up, the lighting becomes more accurate because the light from the bouncing gets everywhere.

The M is allowed to go way higher because of the Russian roulette cutting out some of the rays. So for the normal one, it only went up to 5 but with Russian roulette it was able to go up to 100.

The noise drops as the samples per pixel goes up. Because it has more values to average, and so it's just going to get a more accurate number for that pixel.

Part 5: Adaptive Sampling

Adaptive sampling is basically trying to just use the necessary amount of samples per pixel. The way it does this is by using confidence intervals and basically checking if a pixel is within a certain accuracy with a 95% chance. So the certain accuracy is the max tolerance, and that is passed in. The way it does this is by keeping running sums of the light/illumination and the light squared. And then it uses this to compute the mean, the variance, and the confidence radius. And then using the confidence radius, if it is with certain certainty, then it'll stop shooting out more rays. Otherwise, it'll keep shooting out rays in the batches that are predefined.
